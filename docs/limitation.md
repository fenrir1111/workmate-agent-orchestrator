# 已知局限（很重要）

1. **面向可控流程编排，不是通用自主规划 Agent**：不支持超复杂长链路、开放式自我规划，
   节点顺序与分支由画布定义，模型能力只体现在"工具产出"而非"路径规划"。
2. **人工节点需对接企业消息通知系统**（飞书 / 钉钉 / 企业微信）才能推送审批人，
   当前 `noop` 为占位动作，通知推送为适配器。
3. **单进程内存态**：运行中任务（`FlowRun`）保存在进程内存，适合 POC 与单租户；
   多实例高可用需外置状态存储（DB / Redis）并基于快照恢复。
4. **内置工具为确定性模拟**：`builtins` 的 SQL / RAG / OCR 为离线假数据，
   生产需替换为真实实现或接入 examples/ 里的 HTTP 适配器。
5. **超时用线程池模拟**：`timeout` 通过 `ThreadPoolExecutor` 实现，超时线程在后台自行结束，
   非强杀语义；对长耗时、不可中断的外部调用需业务侧自行兜底。
6. **条件门为简单判定**：支持 eq/ne/gt/lt/contains/exists 等基础操作，不支持复杂表达式树。
7. **不支持并行分支 / 循环**：当前为线性流程 + 条件跳过；并行会聚、循环回退为后续版本能力。
