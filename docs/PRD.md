# PRD｜workmate-agent-orchestrator 轻量企业数字员工编排平台

## 1. 产品定位
面向 B 端交付 POC 快速验证数字员工场景，拒绝盲目追求全自动 Agent；核心思路：
**确定性流程自动化，高风险节点强制人工介入、留痕审计**。
轻量化编排底座，给 FDE 快速搭建客户演示方案，可控、可审计、可人工接管。

## 2. 用户角色
- FDE 交付：快速编排 Agent 流程，给客户做 POC 演示
- 方案架构师：注册工具、定义 Agent 权限白名单
- 业务审批人：接收人工节点审批、干预 Agent 任务
- 审计人员：查看任务执行链路、工具调用记录

## 3. 用户故事
1. 作为交付，我需要可视化画布编排任务流程，不用大量写代码快速搭建数字员工
2. 作为管理员，我需要注册工具：SQL 查询、RAG 检索、HTTP 接口、消息通知
3. 作为安全负责人，每个 Agent 绑定工具白名单，不能随意调用高危工具
4. 作为流程设计者，高风险节点设置人工介入分支，模型不能自主执行
5. 作为运维，我需要查看完整执行日志、任务快照、SLA 告警

## 4. 核心功能清单
1. 可视化流程画布编排任务节点（JSON 定义，`data/flows.json`）
2. 工具注册中心：SQL、RAG、HTTP、消息通知工具
3. Agent 权限白名单：流级 / 步骤级 / 工具级 三级控制可用工具
4. 状态机驱动任务、失败重试、超时控制
5. 人工介入分支节点，支持人工审批 / 驳回（HITL）
6. 全链路执行日志、任务快照（可挂起 / 恢复）
7. SLA 告警、任务超时通知
8. Agent 方案包导入导出，交付 POC

## 5. 非功能需求
1. 主打可控流程编排，不做通用自主规划 Agent
2. 可对接飞书 / 钉钉消息通知（人工节点通知）
3. 私有化部署，任务日志本地留存
4. 兼容 LiteLLM 多模型（接真实 LLM 工具时）

## 6. 验收标准 v0.1
1. docker-compose 拉起
2. 画布编排简单任务，工具调用正常
3. 人工节点触发、日志落库
4. 支持导出方案包

## 7. 迭代路线
- v0.1：画布编排、工具注册、人工节点、审计日志
- v0.2：SLA、重试策略、告警
- v0.3：对接 eval-harness 评估 Agent 成功率
- v0.4：POC 模板市场、方案包共享
